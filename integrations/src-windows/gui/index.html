What this installs and sends
Three scripts run locally as Claude Code hooks: anchor_hook.js, heartbeat_daemon.js, log_forwarder.js.
  • Session start/end, prompts (truncated to 500 chars), tool calls and results (truncated) are written to a local log file.
  • Your OS username and machine hostname are detected locally each time a hook runs — nothing is hardcoded by this installer.
  • A background process ships new log lines to your organization's Tally endpoint over HTTPS using the API key you provide below.
  • Nothing is sent anywhere during installation itself — only after you finish setup and start a Claude Code session.
Stored locally at ~/.claude/tally/logs/.state/api_key.txt, readable only by your account.
